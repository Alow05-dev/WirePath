## Trades included

- Electrical — 2026 NEC planning tools from the existing WirePath build
- HVAC — preliminary duct/airflow, cooling-load, refrigerant-line, and equipment electrical planning
- Plumbing — preliminary water flow, drainage fixture units, water-heater, and pressure-loss planning
- Telecom / Data — PoE budget, cable footage, fiber-loss, and pathway-fill planning

## Important

The non-electrical modules are planning tools, not a claim of universal code compliance. Code adoption varies by jurisdiction, and final work must be checked against the adopted code/standard, AHJ requirements, project specifications, and manufacturer instructions.

Electrical references are designed around the 2026 NEC baseline. NFPA identifies the 2026 NEC as the current edition. HVAC/plumbing examples reference the 2024 IMC/IPC framework, while telecom/data references the applicable TIA structured-cabling standards.

Do not reproduce copyrighted code or standards text in the app. Use section/standard identifiers, original explanations, formulas, and links/references where permitted.
