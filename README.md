# Angler Adam's Fishing Guide — V3

Mobile-first fishing guide for GitHub Pages.

## Files
- `index.html`
- `styles.css`
- `main.js`

## V3 features
- Expanded species list (bass, trout, salmon, panfish, catfish, walleye, pike, muskie, carp, sturgeon and more)
- Fishing depth selector
- Boat vs shoreline
- Baitcasting, spinning, downrigger, trolling and fly setups
- Lure / bait / live bait / artificial presentation
- Setup-aware recommendation engine
- Hard compatibility rule prevents stationary bait such as PowerBait from being recommended for a downrigger setup
- iPhone input zoom prevention: form controls use a minimum 16px font
- Centered responsive layout
- Saved trips and tackle box with localStorage
- GitHub Pages compatible; no server required
